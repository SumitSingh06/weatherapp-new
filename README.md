# Weather App

A fast, responsive weather app built with plain HTML, CSS and JavaScript. Search any city and see its current weather, the next 24 hours and a 7-day forecast.

**Live app:** ADD_YOUR_VERCEL_LINK_HERE

## Features
- Search any city (use `City, Country` such as `Paris, FR` to be specific)
- Other matching places are offered when a name is shared by several cities
- Current temperature, condition, feels like, humidity, wind, pressure, precipitation, sunrise and sunset
- Next 24 hours and 7-day forecast
- °C / °F switch (remembered in the browser)
- "Use my location" button
- Recent searches (stored in the browser only)
- Background colours change with the weather and day/night
- Clear messages for an empty search, unknown city, no internet, slow or unavailable service
- Responsive layout for desktop and mobile

## Technologies
HTML, CSS, JavaScript and the [Open-Meteo](https://open-meteo.com/) geocoding and forecast APIs (free, no API key needed, so there is no secret to protect).

## Run locally
Open `index.html` in a web browser.

## Deployment
Static site hosted on Vercel from this GitHub repository. No environment variables are needed.

## Data
Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0).
